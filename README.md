# 🧸 Stony – 부모의 목소리로 완성되는 AI 동화 서비스

아이와 함께하는 시간이 부족해지고,  
어쩔 수 없이 스크린 육아가 늘어나는 시대에  
**“부모 목소리만큼 아이에게 따뜻한 건 없다”**라는 생각으로 시작했어요.

Stony는 부모님의 **목소리**와 **경험**을 기반으로  
아이에게 정서적으로 안전하고 교육적으로 의미 있는 이야기를  
AI가 함께 만들어주는 서비스예요.

## 🆘 문제 인식

### 👶 1. 아이와 함께 보내는 시간이 부족해요  
바쁜 일상 속에서 아이에게 책을 읽어주거나 이야기를 나누는 시간이 점점 줄어들고 있어요.

### 📱 2. 스크린 육아에 대한 걱정이 커지고 있어요  
영상 콘텐츠는 편하지만, 아이의 발달에 ‘좋은 자극’이 되는지 걱정이 많아요.

### 🎧 3. 부모님의 목소리는 아이에게 큰 영향을 줘요  
부모 목소리는 안정감·애착·감정 발달에 긍정적인 영향을 줘요.  
그래서 **부모의 목소리 + 부모의 경험 + AI 동화 생성**을 결합해  
아이에게 한 걸음 더 가까이 다가가고 싶었어요.

---

## ✨ 주요 기능

### 🎤 1. 부모 보이스 클로닝  
부모님의 실제 목소리를 AI가 자연스럽게 복제해요.  
아이에게 언제든지 “엄마/아빠 목소리로 읽어주는 동화”를 들려줄 수 있어요.  
- 짧은 녹음만으로 보이스 클론 생성  
- 자연스럽고 따뜻한 목소리 유지  
- 생성된 동화 전체를 부모 목소리로 재생 가능  

---

### 📖 2. 부모 경험 기반 AI 동화 생성  
부모님의 어린 시절 이야기, 배우고 느낀 점, 아이에게 전하고 싶은 메시지를  
AI가 동화 구조에 맞게 자연스럽게 재구성해요.  
- 부모 경험에서 감정·사건·교훈 키워드 추출  
- 3막/5막 구조로 이야기 정리  
- 아이 연령에 맞는 표현으로 동화 제작  
- 부모가 원하면 여러 번 재생성 가능  

---

### 📘 3. 명작 동화 확장  
아이와 함께 익숙한 명작 동화에 새로운 상상력을 더해요.  
- 기존 동화의 **뒷이야기**, **새로운 사건**, **다른 결말** 생성  
- 아이가 선택한 키워드에 따라 장면 변화  
- 완성된 동화를 다시 부모 목소리로 들려줄 수 있음  

---

### 🧠 4. 아이 발화 분석 리포트  
아이의 말하기 데이터를 기반으로  
언어 능력과 성향을 가볍게 확인할 수 있는 리포트를 제공해요.  
- NDW, TKN 등 언어 분석 지표 활용  
- 월간 변화 추적  
- 부모가 아이의 성장 포인트를 쉽게 파악할 수 있음
